# Shelf
Basic SQL provider tool

## Brief Description
This project is a tool for simplifying interaction with data in database.

## Functional Tasks
- Generate SQL queries from LINQ expressions.
- Provide a simple models for interraction with database.
- Track changes made on models by user and write them in database.

## Technical Goals
- **Programming Languages**: C#
- Write my own algorithms of generating SQL queries from LINQ expressions.
- Write my own models for interraction with database.
- Write my own classes for tracking changes made on models by user and write them in database.
